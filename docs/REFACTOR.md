# 重构与验证记录

## 目录边界

目标为 `boardGameAI/patchwork`，参考 `Jaipur` 的分层，不复制 Jaipur 的游戏逻辑、训练模型或美术资源。原 `script/patchwork` 保留独立的命令行版本，其缺陷修复记录见原目录 `CHANGES.md`。

开始任务时，目标目录为空，Git 中旧 `patchwork/cpp/*` 处于已删除状态。新项目创建独立的 `cpp/engine.hpp`、`search.hpp`、`bridge.cpp`、`data.hpp`，不恢复旧的已删除文件。未提交或推送代码。

## 修正

1. 终点第 53 格的收入结算。
2. 一次跨过多个皮革点全部领取，逐块放置后再切换行动者。
3. 被子已满时丢弃无法放置的多余皮革，避免无合法行动而卡死。
4. 记录第一个到达终点的玩家，终局同分按此判胜。
5. 初始中立标记位于 1 × 2 拼块之后。
6. 拼块外围空白规范化，恢复遗漏的边缘落点，数据生成顺序确定。
7. 界面、存档和 C++ ABI 均通过合法行动验证；购买不能越界、重叠、超出市场或透支。
8. Worker 在菜单、规则、暂停和回放时终止；旧任务不能提交过期结果。

原目录另外修复了有符号负数移位、零预算空数组访问、输入越界和落点不精确等问题。先验权重只算一次，随机删除改为 swap/pop，搜索线程上限 8，剩余收入次数精确计算；这减少重复工作，但没有声称固定比例的加速。
